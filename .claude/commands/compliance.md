# compliance

Check privacy and local record evidence.

Run from the repository root:

```bash
npm run spend -- compliance
```

Use --json when comparing records. Read full evidence and history before drawing conclusions. Present missing values as unknown. Never combine currencies. Never send, buy, cancel, revoke or contact a vendor.

Read docs/compliance.md. Explain each finding with its cited rule. These are record checks, not a certification of security, legal compliance or contract validity.
