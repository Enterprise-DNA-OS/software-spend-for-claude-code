# Why a software register has no front end

The weekly work is reviewing renewal dates, asking owners for evidence, comparing licence observations and drafting decisions. A database and agent commands handle that work. Read-only HTML reports let someone review or print the result without changing records.

A screen offers mobile access, concurrent forms, sign-in, permission boundaries and direct connections to vendors. This free version has none of those interfaces. It neither discovers shadow accounts nor provisions, revokes or cancels anything. Imported and manually recorded evidence is only as current as its source date.

The local embedded database suits one trusted operator. Hosted Postgres allows a shared database connection, but team authentication and role enforcement need an agreed installation.
