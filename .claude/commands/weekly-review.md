# weekly-review

Draft the Monday renewal, licence and evidence review.

Run from the repository root:

```bash
npm run spend -- weekly-review
```

Use --json when comparing records. Read full evidence and history before drawing conclusions. Present missing values as unknown. Never combine currencies. Never send, buy, cancel, revoke or contact a vendor.

The CLI writes a dated file to drafts/. Review the evidence and state the action owner. For the Monday review it reads notice-deadlines, licence-review and compliance. Do not send the result.
